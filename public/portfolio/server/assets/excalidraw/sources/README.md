# Excalidraw source bundle

This folder is generated by `tools/export-vault-qmd.js`.

- `excalidraw/`: original Obsidian Excalidraw files copied from the Vault
- `svg/`: SVG files used by the rendered Quarto document
- `mermaid/`: extracted Mermaid sources when the QMD contains Mermaid fences

The authoritative mapping is `../manifest.json`.
